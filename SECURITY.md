# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 3.x     | Yes       |
| < 3.0   | No        |

## Reporting a Vulnerability

Report vulnerabilities privately. **Do not open a public issue.**

Email **security@sinemacula.co.uk** with:

- A description of the vulnerability
- Steps to reproduce or a proof of concept
- The affected version(s)

You will receive an acknowledgement within 48 hours, and a fix will be coordinated with you before any public
disclosure.

## Disclosure Policy

- Fixes are released as a new version
- Credit will be given to the reporter unless they prefer to remain anonymous
- Public disclosure will be coordinated with the reporter after a fix is available
